# Automated Technical SEO & Audit Tool (Python)

A scalable Python-based SEO tool designed to automate technical site audits, fetching critical on-page SEO metrics instantly to replace manual source-code verification.

## 🚀 Core Features
- **Response Validation:** Captures HTTP status codes (200, 404, etc.) to detect broken links and crawl errors.
- **On-Page Extraction:** Automatically audits Meta Titles, Meta Descriptions, and H1 hierarchy tags.
- **Performance Benchmarking:** Measures server response latency to spot speed and Core Web Vitals bottlenecks.
- **Data Export:** Compiles live site metrics into a structured CSV format ready for strategic diagnostic reviews.

## 🛠️ Tech Stack & Tools Used
- Python 3
- Beautiful Soup 4 (For web scraping & HTML parsing)
- Pandas (For data structuring)
- Requests (For simulating search engine bot requests)
- Google Colab
